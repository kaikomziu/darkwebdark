# DarkWebDark

ブラウザで遊ぶ、ネットサーフィン型のホラーゲームです。

最初はただの平和な個人ブログ「ひだまり日記」。記事を読み進めるうちに、だんだん様子がおかしくなっていき……。

> ⚠️ 大きな音・突然の驚かし（ジャンプスケア）・点滅表現があります。

## 遊び方

- `index.html` をブラウザで開けば始まります（サーバー不要）。
- GitHub Pages で公開する場合：リポジトリの Settings → Pages → Branch を選んで保存してください。
- スマホ・PC 両対応（タップ／クリック、PCはスペースキーにも対応）。
- 進行状況はブラウザ（localStorage）に保存されます。最初からやり直すときは、クリア後のブログにある「さいしょから」を押してください。

### RTAモード（1回クリアで解放）

- クリア後のブログに「RTAモード」が出ます。「RTA開始」から最深部の「そとへ」を押すまでのタイムを計測します（画面右上にタイマー表示、2回押しで中断）。
- 自己ベストはブラウザに保存されます。
- オンラインランキングは1人1件、自分の最速タイムだけが残ります。
  - **GitHub Pages 版**（`https://kaikomziu.github.io/darkwebdark/`）：Supabase に保存。だれでも登録できます（ブラウザごとの匿名IDで1件）。
  - **claude.ai 公開ページ版**：外部への通信ができないため、claude.ai の共有データベースに保存（組織のメンバーのみ登録可）。

### Supabase の準備（最初の1回だけ）

Supabase ダッシュボード → SQL Editor に `supabase/dwd_rta.sql` を貼り付けて実行してください。テーブル `dwd_rta_scores` と登録用関数 `dwd_submit_rta` が作られます（他のテーブルには触れません）。

## 構成

| 場所 | 内容 |
| --- | --- |
| `index.html` | 表のブログ「ひだまり日記」（読み進めるほど不気味になる／エンディングの舞台） |
| `blog/1〜5.html` | ブログ記事。5記事目からリダイレクトされて本番へ |
| `dwd/index.html` | LAYER 01 入口：扉を選ぶ |
| `dwd/2/` | LAYER 02 写真：あの子の名前をよぶ |
| `dwd/3/` | LAYER 03 管理人：チャット → 長い下り坂 |
| `dwd/4/` | LAYER 04 ろうか：音を聞いて扉をえらぶ |
| `dwd/5/` | LAYER 05 最深部：見られている間は動かない |
| `dwd/404.html` | 罠ページ |
| `end.html` | エンディング |
| `assets/dwd.js` | 共通エンジン（効果音合成・驚かし・グリッチ・セーブ） |

効果音は外部ファイルを使わず、すべて Web Audio API で合成しています。驚かしの絵もキャンバスで描画しています。
